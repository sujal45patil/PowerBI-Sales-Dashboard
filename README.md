# Power BI Sales Dashboard

This is a beginner-friendly Power BI project.

## Features
- Total Sales Analysis
- Profit Tracking
- Monthly Sales Report
- Data Visualization

## Tools Used
- Power BI
- CSV Dataset

## How to Use
1. Open Power BI Desktop
2. Import the dataset
3. Create charts and KPI cards
4. Save the project as `.pbix`
5. Upload to GitHub
