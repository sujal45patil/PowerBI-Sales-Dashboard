# Project Overview

This Power BI dashboard project focuses on analyzing sales and profit performance across different regions and products.

## Objectives
- Analyze monthly sales trends
- Identify top-performing products
- Track profit growth
- Visualize regional performance

## Key Insights
- Laptop category generated highest sales
- West region showed strong performance
- Sales peaked during April

## Future Improvements
- Add forecasting
- Add customer segmentation
